# CircleLauncher

A minimal circular launcher for Android, focused on a simple and fast home-screen experience.

## Overview
CircleLauncher explores a clean launcher layout with circular visual elements and a deliberately lightweight approach.

## Project
- Platform: Android
- Language: Java

## Getting started
1. Clone the repository.
2. Open the Android project in Android Studio.
3. Let Gradle sync, then build and install it on a test device.
4. Set it as the default home app only if you want to try it as your launcher.

## Notes
Launcher behaviour and available features are defined by the current source code. Test changes on a device where you can easily switch back to your usual home app.

## Status
Experimental project; functionality may change.
